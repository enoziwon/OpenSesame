# 정답 달기 도구 (label_tool.html)

1. `label_tool.html`을 브라우저(크롬·엣지·사파리)로 바로 연다. 서버도 인터넷도 필요 없다(사진 링크만 HACCP 사이트로 새 탭에서 열린다).
2. 위쪽 '라벨러'에 이름을 넣는다. 한 번 넣으면 브라우저에 남는다. 이름이 없으면 제품을 완료할 수 없다.
3. '파일'에서 `data/raw/gold/dev_blank.jsonl`(또는 작업 중인 `*_labeled.jsonl`)을 연다. 개발 세트를 먼저 단다(가이드 8장).
4. 1~9로 알레르기 줄을 고르고 q 없음 · w 확인됨 · e 추정 · r 판정 불가. 원재료 글자를 드래그하면 그 줄의 근거로 들어가고, t를 누르면 근거 입력칸(자동 완성)으로 간다. 표시란 낱말을 누르면 "표시란: X".
5. h 숨은·유래, k 표시란에 있음(표시란 낱말로 미리 계산, 고칠 수 있음), Shift+1~8 근거 코드(US-SRC … POSSIBLE), n 예외 메모, m 제품 메모. 입력칸에서는 Esc나 Enter로 나온다.
6. Enter는 '완료하고 다음 미완료 제품'. ←/→ 이전·다음, u 미완료만 보기, g 가이드 요약 펼치기. 위쪽에 '완료 n / 전체'가 보인다.
7. 진행은 브라우저(localStorage)에 파일 이름별로 자동 저장된다. 창을 닫았다가 같은 파일을 다시 열면 이어서 단다. 브라우저 데이터를 지우면 사라지므로 자주 내보낸다.
8. '내보내기'(Ctrl+S 또는 ⌘S)는 스키마(필수 칸, 값 범위)를 검사하고, 판정이 있는데 근거가 빈 줄·근거 코드 없음·미완료 제품을 경고한 뒤 `<이름>_labeled.jsonl`로 저장한다.
9. 이 도구는 시스템 결과, LLM 제안, 사전 판정을 보여 주지 않는다. 시험 세트는 가이드·법령 원문·라벨 사진·일반 검색만 보고 단다.
10. 내보낸 jsonl은 한 줄이 스키마 레코드 하나다(`data/schema/label_record.schema.json`). 시험 세트를 다 달면 가이드 8장 7번대로 파일 SHA-256으로 잠근다.
