# EXP-002 LLM 베이스라인 프롬프트 (통과 조건 ②)

**원칙**: 사람마다 모델·프롬프트가 다르면 결과를 합칠 수 없다. 아래 프롬프트를 그대로 쓴다.
프로필은 **가상 프로필**만 쓴다. 실제 사람의 알레르기 정보를 넣지 않는다.

## 프롬프트 A — 사진 입력
```
이 사진은 한국 가공식품 뒷면 라벨입니다. 사용자는 미국인 관광객이고, 알레르기 프로필은 다음과 같습니다: {{PROFILE}}
(1) 원재료명을 보이는 그대로 전사하세요.
(2) 프로필의 각 항목에 대해, 이 제품의 원재료명에 포함되었는지 "확인됨 / 추정 / 판정 불가 / 검출 안 됨" 중 하나로 답하고 근거 원재료를 적으세요.
(3) 프로필에 없는 항목은 판단하지 마세요.
```

## 프롬프트 B — 텍스트 입력 (원재료 줄만)
```
다음은 한국 식품의 원재료명입니다. 미국 FDA 기준 주요 알레르겐(우유, 달걀, 생선, 갑각류, 견과류, 땅콩, 밀, 대두, 참깨) 중
이 원재료명에 포함되었거나 포함되었을 가능성이 있는 것을 모두 고르세요.
각 항목마다 근거 원재료를 적고, 확실하지 않으면 "불확실"이라고 표시하세요.

원재료명: {{INGREDIENTS}}
```

## 기록할 것 (제품·모델당)
1. 놓친 알레르겐이 있는가 (정답 전사와 비교)
2. 원재료에 없는 것을 지어냈는가
3. 같은 입력을 3번 돌렸을 때 답이 바뀌는가
4. "불확실"/"판정 불가"를 적절히 쓰는가
5. 프로필에 없는 항목을 멋대로 판단했는가 (프롬프트 A)

## 어려운 원재료 후보 (10줄을 채워 넣기)
- 혼합조미분말, 양념, 복합조미식품 속 성분
- 어육·어묵·액젓·젓갈류
- 카제인나트륨, 유청분말, 레시틴
- 참기름·참깨 포함 소스
- 괄호가 중첩된 혼합제제
