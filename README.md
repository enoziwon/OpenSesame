## 주제

한국 포장식품 라벨의 **원재료명**을 읽어, 미국인 관광객이 사전에 입력한
**본인의 알레르기 정보**를 바탕으로 알레르기 유발 성분을 검출하고
**구매 전에 경고**하는 시스템. 결과는 **미국 의무 표시 알레르겐 9개 기준**으로 보여준다.

## 문제

- 한국어 원재료명은 겹괄호와 복합 원재료로 이어진 긴 문장이라 관광객이 읽을 수 없다.
- 한국의 의무 표시는 19개 항목이고 미국은 9개 항목이다. 두 목록은 구성이 달라서
  한국 표시란만으로는 미국 기준 위험을 알 수 없다.
  - 예: 참깨는 미국에서는 의무 표시지만 한국 19개에는 없다.
  - 예: 미국의 fish는 모든 생선이지만, 한국 19개 중 생선은 고등어뿐이다.
- 번역은 글자를 옮길 뿐, 그 성분이 내 알레르기에 해당하는지는 판단하지 않는다.

## 사용 흐름

1. 관광객이 미국 의무 표시 알레르겐 9개 중 본인의 알레르기를 선택한다. (사전 입력)
2. 마트에서 라벨의 원재료명을 촬영한다.
3. 시스템이 원재료명에서 성분을 추출하고 9개 알레르겐으로 분류한다.
4. 선택한 알레르기와 대조해 영어로 경고하고, 근거가 된 성분을 함께 보여준다.

## 결과 표시

- 미국 의무 표시 알레르겐 9개 기준으로 표시한다.
- 3단계로 판정한다: **확인됨 / 추정 / 판정 불가**
- 항상 **근거 성분**을 함께 보여준다.
- **미검출은 안전이 아니다.** 시스템은 안전하다고 단정하지 않는다.

## 범위

| 포함 | 제외 |
|---|---|
| 한국 포장식품의 원재료명 | 식당 메뉴, 조리 식품 |
| 미국 의무 표시 알레르겐 9개 | 9개 밖의 개인 알레르기, 다른 나라 기준 |
| 영어 경고 | 다른 언어 |
| 가상 프로필로 개발·평가 | 실제 사용자의 알레르기 정보 수집 |

## 개인정보 원칙

알레르기는 건강 정보다. 입력한 정보는 서버에 저장하지 않고 사용 중에만 쓰며,
로그에도 남기지 않는다.

## 결과물

1. **제품**: 알레르기를 선택하고 라벨을 찍으면 영어 경고가 나오는 웹앱
2. **모델**: 겹괄호와 '유래·추출물' 같은 표현 속 성분을 9개 알레르겐과 연결
3. **평가**: 놓친 알레르겐에 가중치를 둔 지표로 측정하고, 모르면 '판정 불가'로 답함
