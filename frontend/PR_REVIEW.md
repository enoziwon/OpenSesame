# PR 리뷰 반영 및 회의 안건

## 반영 내용

- 결과 배지는 `Safe` 대신 `Not detected`를 사용합니다. 분석이 불완전한 경우에는 `Cannot determine`으로 표시합니다. 기존 최신 커밋에 불확실한 개인 판정의 주의 안내가 포함되어 있습니다.
- 카메라는 `<input type="file" capture="environment">` 방식이며 `getUserMedia`를 사용하지 않습니다. 실제 모바일 촬영은 별도 기기 검증이 필요합니다.
- README에 Mac/Linux 설치·실행 명령과 실제 LLM 검증 설정을 추가했습니다.
- Playwright의 서버 실행 명령을 `npm.cmd`에서 `npm`으로 바꿔 Mac/Linux에서도 사용할 수 있도록 했습니다. Mac/Linux 실행 자체는 아직 검증하지 않았습니다.

## 회의에서 결정할 내용

### 프로필 저장 정책

현재 최신 커밋은 `localStorage`의 `opensesame.allergies` 키에 선택한 알레르겐 ID를 저장합니다. 새로고침과 브라우저 재시작 후에도 유지되며 서버로 전송하지 않습니다. 사진과 분석 결과는 메모리에만 둡니다.

팀에서 저장 방식을 확정한 상태는 아닙니다. 편의성을 위해 현재 구현은 유지하되, 아래 사항을 회의에서 결정해야 합니다.

- `sessionStorage`: 탭 세션 범위로 사용하고 세션 종료 후 선택을 다시 입력할지.
- `localStorage`: 브라우저 재시작 후에도 유지할지. 공용 기기에서 다음 사용자에게 선택 정보가 남을 수 있습니다.
- 영구 저장을 선택한다면 저장 안내·사용자 동의 방식, 전체 삭제 기능, 보관 기간을 어떻게 정할지.
- 루트 README의 “사용 중에만 쓴다”는 개인정보 원칙과 최종 저장 정책을 일치시킬지. 현재 영구 저장은 이 원칙과 함께 검토해야 합니다.

### 실제 LLM 및 모바일 검증

- 2026-11-12 GitHub 확인: BAZE 연결 구현은 미머지 [PR #7](https://github.com/enoziwon/OpenSesame/pull/7)에 있으며 현재 프론트엔드 브랜치에는 없습니다. 현재 코드는 Anthropic 직접 연결 방식입니다. 검증하려면 PR #7을 별도 통합 테스트 브랜치에 반영하거나 머지 후 최신 백엔드를 받아야 합니다. 키 설정만으로 해결되는 상태가 아닙니다.
- 로컬에 루트 `.env`가 없어 실제 LLM 검증에 사용할 키를 확인하지 못했습니다. 실제 LLM 화면 검증은 미완료입니다. 키를 발급·설정한 뒤 `inferable`/`undecidable` 혼합 응답의 배지, 근거, 주의 안내를 확인해야 합니다.
- OCR을 Mock으로 두고 LLM만 검증할지, 실제 사진의 OCR까지 포함해 검증할지 범위를 정해야 합니다.
- iOS Safari·Android Chrome에서 카메라 호출, 파일 선택, 업로드를 확인할 담당자와 기기를 정해야 합니다.

테스트 재실행 결과는 [검증 보고서](VERIFICATION.md)에 기록합니다. 실제 LLM 검증과 Mock 응답을 사용하는 브라우저 테스트는 구분합니다.
