# 원재료 사전 v0 (최종본 5단계)

원재료 이름 하나가 무엇에서 왔는지를 적은 표다. 최종본은 이 표를 먼저 보고, 표에 없는 이름만 다음 단계(이름 모델이나 LLM)로 넘긴다.
판정 기준은 정답지 가이드와 같다. 미국 FDA 주요 알레르기 9개만 센다.

```python
from src.final.lexicon import lookup
r = lookup("양조간장")
r.us       # {'soy': 'C', 'wheat': 'I'}
r.via      # 'entry'
```

## 파일

| 파일 | 내용 | 줄 수 |
|---|---|---|
| `sources.tsv` | 출처 코드표. 코드마다 미국 9개 중 무엇인지, 한국 표시란 낱말, 영어·한국어 이름 | 65 |
| `rules.tsv` | 키워드 규칙. 포함어와 제외어로 이름을 가린다 | 83 + 4 |
| `entries.tsv` | 정확 일치 사전. 사람이 훑어본 항목 | 2,508 |
| `entries_auto.tsv` | 자동 단. 규칙에도 없고 초벌 LLM 라벨도 '관계없음'이었던 이름. 검수 전 | 2,190 |
| `kr_box.tsv` | 한국 알레르기 표시란 낱말과 출처 코드, 현행 의무 여부 | 37 |

출처 코드는 두 층으로 쓴다. `fish:anchovy`처럼 무엇인지를 먼저 적고, 그것이 미국 9개 중 무엇인지는 `sources.tsv`가 정한다.
`mollusk:squid`, `perilla`, `coconut`처럼 미국 9개가 아닌 것도 코드를 둔다. 무엇인지 안다는 표시이고, 기준표만 바꿔 다른 나라 기준으로 넓힐 수 있다.

## 등급

| 등급 | 뜻 | 예 |
|---|---|---|
| C 확정 | 이름 자체가 그 원료이거나 정의상 그 원료로 만든다 | 참기름, 카제인나트륨, 연육, 빵가루 |
| I 추정 | 대개 그 원료로 만들지만 아닐 수 있다 | 간장의 밀, 레시틴의 대두, 액젓의 생선, 김치의 생선 |
| P 가능 | 들어가는 경우가 드물지 않다. 표시란으로 확인되지 않으면 판정 불가의 근거가 된다 | 전분의 밀, 육수의 생선, 그래놀라의 견과류 |
| R 정제유 | 고도 정제유와 거기서 얻은 성분. 미국 기준으로는 세지 않는다 (대두만) | 대두유, 콩기름, d-토코페롤 |
| F 유지 | 종류가 적히지 않은 유지. 대두유일 수 있다 (대두만, 가이드 R1-1) | 식물성유지, 쇼트닝, 마가린 |

`flags` 칸: `O` 속을 알 수 없는 복합 원료(가이드 5장), `V` 일반 향료(가이드 D5), `X` 원재료가 아닌 표기(원산지, 기준 문구).

## 찾는 순서

1. 이름을 소문자로 바꾸고 이음표·가운뎃점·공백을 뺀다.
2. 정확 일치 사전에서 찾는다. 없으면 `밀-미국산`처럼 붙은 원산지를 떼고 다시 찾는다.
3. 키워드 규칙을 적용한다. 제외어를 먼저 지우고 포함어가 남으면 맞은 것이다. 당밀·오트밀은 밀이 아니고, 발아귀리는 아귀가 아니다.
4. 맛·향 이름이면 한 단계 낮춘다. 새우맛분말은 새우 추정, 초콜릿향은 우유 가능이다.
5. 어디에도 없으면 자동 단을 보고, 거기에도 없으면 모르는 이름(`via == "unknown"`)으로 돌려준다.

## 만든 방법

1. 2020년 HACCP 포장지 표기 공개 자료(제품 15,451개)를 최종본 파서로 풀어 원재료 이름 23,550개와 빈도를 뽑았다.
2. 같은 자료에서 근거 숫자 두 가지를 셌다.
   - 표시란 근거: 다른 원재료로는 그 알레르기가 설명되지 않는 제품 가운데 표시란에 적은 비율. 양조간장은 밀 96%, 난각칼슘은 달걀 97%, 유화제는 대두 29%(설탕 31%와 같은 수준).
   - 하위 원료 근거: 괄호로 하위 원료가 적힌 사례에서 그 알레르기 원료가 보인 비율. 빵가루는 밀 99%, 마요네즈는 달걀 97%, 식물성크림은 우유 91%, 전분은 밀 35%.
3. 키워드 규칙을 쓰고 어휘 전체에 돌려, 규칙마다 잡힌 이름을 훑으며 제외어를 채웠다.
4. 자주 나오는 이름 2,000개를 하나씩 훑어 규칙 결과를 고치거나 직접 정했다.
5. 팀 시드 사전(882행)을 옮겨 넣었다. 규칙과 다르게 본 175건을 훑어 48건은 규칙을 따르고 20여 건은 다시 정했다. 나머지는 시드 사전을 따른다.
6. 파일럿 때 Gemini로 붙인 초벌 라벨은 대조용으로만 썼다. 규칙에는 없는데 초벌이 양성으로 본 이름 290개를 훑어 빠진 표현(지단, 컴파운드 초콜릿, 가다랭이 등)을 건졌다.

## 덮는 범위 (2020년 자료의 원재료 언급 282,927건 기준)

| 처리 경로 | 비중 |
|---|---|
| 정확 일치 사전 | 82.3% |
| 키워드 규칙 | 7.7% |
| 자동 단 (검수 전) | 4.5% |
| 모르는 이름 | 5.5% |

모르는 이름의 상위는 상표 이름(미감에스유, 호스이엔알 등)이다.

## 한계와 정할 것

- 사람 검수 전이다. `status` 칸이 `확인`이어도 Claude가 훑어봤다는 뜻이다. `검수요청` 11건과 `시드검증필요` 154건부터 본다.
- 어휘와 근거 숫자는 2020년 자료에서 나왔다. HACCP API 키가 나오면 최신 자료로 다시 낸다.
- 영어 이름은 손으로 정한 항목과 시드 항목에만 있다.
- 정답지 가이드와 함께 정할 것
  - 유화제: 가이드 D2 초안은 대두 추정이지만 표시란 근거가 없어 여기서는 가능(P)으로 낮췄다.
  - 가능(P) 등급: 가이드에는 없는 등급이다. 육수·해물·그래놀라처럼 일부만 해당하는 이름에 쓴다.
  - 속 모를 원료의 범위: 조미·소스·시즈닝처럼 섞은 것이 이름에 드러나는 말로 정했다. 김치·초콜릿 같은 이름 있는 가공식품은 넣지 않았다.
  - 알레르기 이름이 든 향료(헤이즐넛향 등): 가이드대로 추정으로 뒀다. 합성 향료가 많아 가능(P)이 더 맞을 수 있다.
- 시험 세트(정답지 140개)를 달 때는 이 사전을 보지 않는다.

## 고치는 법

TSV를 직접 고치고 `python -m pytest -q tests/test_final_lexicon.py`를 돌린다. 형식이 깨지거나 헷갈리는 이름의 판정이 바뀌면 테스트가 알려 준다.

## AI 사용 기록

표의 초안은 Claude Code(Claude Fable 5.2)로 만들었다. 규칙 작성, 자주 나오는 이름 2,000개의 판정, 시드 사전과의 대조를 Claude가 했다.
파일럿의 초벌 라벨은 Gemini Flash-Lite가 붙인 것이고 대조에만 썼다. 사람 검수 결과는 `status` 칸에 남긴다.
