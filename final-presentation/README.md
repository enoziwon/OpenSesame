# 최종 발표 포스터 시안 (6번·8번 칸)

포스터(Figma)에 넣을 6번 '판정 방식과 근거'와 8번 '효과 및 개선' 칸의 시안이다. 담당은 정형식.

| 파일 | 쓰는 곳 |
|---|---|
| `*_figma.svg` | Figma 화면에 끌어다 놓으면 상자는 도형으로, 글자는 줄마다 글자 레이어로 들어간다 |
| `*_시안.png`, `*_시안.pdf` | 미리 보기 (2416px 폭) |
| `*_포스터문구.txt` | 칸에 들어간 글자 그대로. SVG 글자가 깨져 들어오면 여기서 복사한다 |
| `src/` | 시안 원본(HTML)과 다시 만드는 스크립트: `node src/build.cjs <playwright 모듈 폴더> src/sectionNN.html <출력 폴더>` |

- 글꼴은 Noto Sans KR, 색은 남색 #1F2D4D·주황 #F5823C·회색 #657083이다(재원 님 Figma 초안에서 뽑았다).
- 크기는 2배 포스터(A1, 2546px 폭 프레임)의 가로 전체 칸으로 가정했다. 실제 칸 크기가 다르면 Figma에서 통째로 줄이거나 키운다(K).
- 숫자의 출처는 각 포스터문구 txt 맨 아래와 `experiments/`(EXP-004·006·007)에 있다.
