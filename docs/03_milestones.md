## 이후 (프로젝트 본 일정 — 조정 가능)

최종 발표에는 **작동하는 제품**이 필요하다. 제품은 마지막 단계가 아니라 첫 주부터 병행한다.

| 단계 | 목표 | 산출물 |
|---|---|---|
| 0. 제품 첫 버전 | 프로필 선택 → 사진 → 결과가 끝까지 도는 얇은 버전 (분류기는 LLM) | 배포된 웹앱 |
| 1. 데이터 | API 수집, 사진 촬영·전사 | 원재료 텍스트 + 사진 세트 |
| 2. 정답 | 미국 9개 기준 매핑·gold 검수 | gold 데이터셋 |
| 3. 평가 코드 | 지표·분할·베이스라인·프로필 시뮬레이션 | 평가 프레임워크 (**모델보다 먼저**) |
| 4. 모델 | 파서, 추론, 노이즈 증강 | 학습 결과 |
| 5. 분석 | 입력 조건 비교, 오류 분석 | 결과 표 |
| 6. 통합 | 제품의 분류기를 모델로 교체, 성능 비교 | 최종 제품 |
