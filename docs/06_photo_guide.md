# 06. 라벨 촬영 가이드

## 촬영 규칙
1. **원재료명 + 알레르기 표시란 + 품목보고번호**가 한 장에 들어오게 찍는다.
2. 떨어져 있으면 2장으로 찍고 파일명으로 묶는다: `이름_07_앞.jpg`, `이름_07_뒤.jpg`
3. 플래시를 끈다 (광택 은박 반사). 정면에서 찍고 손 그림자를 피한다.
4. 선반에 꽂힌 채 찍지 말고 꺼내서 찍은 뒤 제자리에 돌려놓는다.
5. 구매는 필요 없다. 라벨만 찍는다.

## 구성 (인당 50장 기준)

| 유형 | 장수 |
|---|---|
| 과자·스낵 | 15~20 |
| 소스·조미료·양념 | 10 |
| 즉석식품·죽·국·간편식 | 8~10 |
| 냉동식품 | 5~8 |
| 음료·유제품·기타 | 5 |

- 원재료 목록이 길고 괄호 중첩이 있는 제품을 우선한다.
- 난이도를 섞는다: 광택 은박, 곡면, 투명 비닐, 작은 글씨.

## 파일명
`이름_제품번호_앞|뒤.jpg` (공유 드라이브에 업로드, 저장소에는 올리지 않음)

## 기록 시트 (제품당 한 행)
`제품번호 / 유형 / 포장 재질 / 품목보고번호 / 미국 9개 알레르겐 포함 목록 / 숨은·유래 표현 여부 / 한국 표시란에 없는 항목 / 촬영 시 어려웠던 점`

- **"숨은·유래 표현 여부"** (복합 원재료, 추출물 등 속에 알레르겐이 든 경우) 열의 합계가 통과 조건 ①의 비율이 된다.
- "한국 표시란에 없는 항목"은 참고 정보다 (판정 기준이 아님).

## 정답 전사 (인당 10장)
- 화질 좋은 5장 + 나쁜 5장을 섞어서 고른다.
- 원재료명 전문과 표시란 전문을 **보이는 그대로** 타이핑한다 (오타·줄바꿈 포함).
- 형식은 `data/schema/label_record.schema.json`을 따른다.

## 마트 촬영 예절
- 매장 방침을 확인한다. 직원이 물으면 학교 과제용이라고 설명한다.
