# 0002. 주제 변경 — 개인 알레르기 프로필 기반 사전 경고 (0001 대체)

- 날짜: 2026-10-15
- 상태: 확정 (통과 조건 ①②는 새 정의로 확인 전까지 조건부)
- 대체: [0001](0001-topic.md)

## 결정

한국 포장식품 라벨의 원재료명을 읽어, 미국인 관광객이 사전에 입력한 본인의 알레르기 정보를 바탕으로 알레르기 유발 성분을 검출하고 사전에 경고하는 시스템. 결과는 미국 의무 표시 알레르겐 9개 기준으로 보여준다.

## 바뀐 것

| 항목 | 0001 | 0002 |
|---|---|---|
| 핵심 산출물 | 벤치마크와 모델 (앱은 데모) | 제품(웹앱) + 모델 + 평가 |
| 사용자 정보 | 없음 | 사용자가 입력한 본인의 알레르기 (개인정보) |
| 판정 기준 | 본국 목록 중 한국 19개 밖 | 미국 의무 표시 9개 중 사용자가 선택한 항목 |
| 대상 국가 | 미국 + EU (최대 1개국 추가) | 미국만 |
| 한국 표시란 비교 | 필수 단계 | 선택 기능 |
| 통과 조건 ① | 한국 19개 밖 알레르겐 포함 제품 비율 | 숨은·유래 표현으로 9개 알레르겐이 든 라벨의 비율 |
| 통과 조건 ② 미달 시 | 기여를 측정·사용 지침으로 이동 | 제품은 유지, 안전 계층(근거·판정 불가·재현성)으로 차별화 |

## 이유

1. 최종 발표에는 작동하는 제품이 있어야 하고, 벤치마크나 프롬프트 가이드만으로는 인정되지 않는다.
2. 사용자가 입력한 프로필과 미국 기준 결과 표시가 합쳐지면 사용 흐름이 한 제품으로 이어진다.
3. 표시 기준을 미국 9개로 고정하면 정답 라벨링과 평가가 명확해진다.

## 새로 생긴 위험

- 차별점이 약해졌다. "프로필 + 사진을 GPT에 주면 되지 않나"에 답해야 한다. 한국어 원재료명의 난이도(겹괄호, 유래·추출물 표현, OCR 오류)와 안전 계층이 근거다.
- 알레르기는 건강 정보다. 저장하지 않는 원칙을 코드에서 지켜야 한다.
- 9개 밖의 알레르기는 다루지 못한다. 화면과 발표에서 한계를 밝힌다.
