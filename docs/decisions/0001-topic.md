# 0001. 프로젝트 주제 확정

- 날짜: 2026-10-09
- 상태: **대체됨 → [0002](0002-topic-personal-profile.md)** (아래는 기록용으로 보존)

## 결정
한국 포장식품 라벨의 원재료명에서, 관광객 본국 기준 알레르겐 중 한국 표시 목록(19개 항목) 밖의 것을 추론해 경고하는 벤치마크와 모델.

## 경위 (기록용)
1. 초기 합의: "원재료 성분으로 표시되지 않은 알레르기 경고".
2. 확인: 한국 법상 포장식품은 알레르겐을 별도 표시란에 적어야 해서, 한국 소비자 대상의 "숨은 성분 추론"은 전제가 성립하지 않음.
3. 검토한 대안: 표시 정합성 검증(국내 회수 사례), 수출 라벨, 외국인 관광객 본국 기준.
4. 선택: **외국인 관광객 본국 기준** — 위반 샘플이 필요 없고, 정상 제품 전체에 문제가 존재하며, 기존 설계를 재사용한다.

## 기각한 대안과 이유
| 대안 | 이유 |
|---|---|
| 앱 개발 중심 | 유사 서비스가 이미 많고 NLP 기여가 약함 |
| 국내 표시 정합성 검증 | 회수 사례가 소수이고 "원재료명에도 없는" 유형의 비율이 미확인 |
| 상용 앱 감사 | 한국에서 못 쓰거나 API가 끊긴 앱이 많아 채점 대상이 안 됨 |

## 미검증 전제 (통과 조건)
- ① 한국 19개 밖 알레르겐 포함 제품 비율
- ② LLM 베이스라인이 어려운 원재료에서 일부 놓치는가 (거의 다 맞히면 기여를 측정·사용 지침 쪽으로 이동)
