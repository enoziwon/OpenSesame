# 01. 문제 정의 (MCS) — 초안

> 상태: 초안 (2026-10-15 주제 변경 반영). 아래 [검증 필요] 표시는 확인 결과로 채운다.
> 평가 구조: Motivation → Claim → Statement가 한 줄로 이어져야 한다.

## Motivation — 왜 이 문제인가

- 한국 방문 외국인 관광객은 편의점·마트의 포장식품을 구매한다. [검증 필요: 관광객 구매 비중 근거]
- 한국어 원재료명은 겹괄호와 복합 원재료로 이어진 긴 문장이라 관광객이 읽을 수 없다.
- 한국의 알레르기 표시 의무 대상은 **19개 항목**, 미국은 **9개 항목**이고 구성이 다르다. 참깨는 미국에만 있고, 미국의 생선·갑각류·견과류는 한국보다 넓다. [검증 필요: 법령 원문 대조]
- 알레르기는 사람마다 다르다. 같은 9개 중에서도 본인에게 해당하는 항목만 알려야 한다.

## Claim — 지금 무엇이 부족한가

1. **표시란이 한국 기준이다.** 한국 법상 정상 표시된 제품이라도 미국 기준 알레르겐이 원재료에 들어 있을 수 있다.
2. **기존 대처는 번역에 머문다.** 번역·알레르기 카드는 글자를 옮길 뿐, `혼합조미분말`, `어육` 같은 복합 원재료 속 성분이 내 알레르기에 해당하는지는 알려주지 않는다. [검증 필요: ② LLM·번역기 실험]
3. **한국 제품에서의 정확도는 측정된 적이 없다.** 시판 알레르기 스캐너의 공개 수치는 출처와 평가 방법이 불분명하다. [검증 필요: 직접 확인한 근거만 인용]

## Statement — 우리가 제안하는 것

> 미국인 관광객이 사전에 입력한 알레르기 정보를 바탕으로 한국 포장식품 라벨의 **원재료명**을 읽어, 알레르기 유발 성분을 **미국 의무 표시 알레르겐 9개 기준**으로 근거와 함께 검출·경고하고, 모르면 **판정 불가**로 멈추는 시스템.

### 결과물
1. **제품**: 알레르기를 선택하고 라벨을 찍으면 영어 경고가 나오는 웹앱
2. **모델**: 겹괄호와 "유래·추출물" 같은 표현 속 성분을 미국 9개 알레르겐과 연결하는 파서·추론 모델 (OCR 노이즈에 강건)
3. **평가 체계**: Seen/Unseen 분할, 누락 가중 재현율, 판정 불가 적절성. 제품이 믿을 만한지 보여주는 근거
4. 한국 라벨 원재료 → 미국 9개 알레르겐 정답 데이터 (법령 조항 기반 gold)

## 예상 반박과 답

| 반박 | 답 |
|---|---|
| 한국은 이미 19개를 표시한다 | 한국 국민에게는 맞다. 대상은 미국 기준이 필요한 관광객이고, 표시란에 없는 참깨 등과 표시란에 없는 유래 표현이 문제다 |
| GPT에 알레르기와 사진을 주면 되지 않나 | GPT는 1번 베이스라인이다. LLM이 잘 맞혀도 제품은 만든다. 근거 성분, 판정 불가, 재현성을 측정한다 |
| 사전 매칭이면 되지 않나 | Unseen 원재료에서 사전은 구조적으로 0%다 (정의상) |
| 이미 앱이 있다 | 한국 제품 정확도가 공개된 앱은 확인하지 못했다 [검증 필요] |
| 알레르기 정보를 받아도 되나 | 서버에 저장하지 않고 사용 중에만 쓴다. 개발·평가에는 가상 프로필만 쓴다 |
| 9개 밖의 알레르기는? | 이번 범위 밖이다. 화면에 "9개 밖은 확인하지 않음"을 밝힌다. 확장 과제 |

## 통과 조건 (주제 유지 기준)

| | 기준 | 미달 시 |
|---|---|---|
| ① | 원재료명에 숨은·유래 표현(복합 원재료, 추출물 등)으로 9개 알레르겐이 들어 있는 라벨의 비율이 충분하다 (기준치는 팀이 정함) | 문제 규모가 작아 재논의 |
| ② | LLM이 어려운 원재료에서 일부 놓친다 | 제품은 그대로 만들고, 차별점을 근거 성분·판정 불가·재현성 같은 안전 계층에 둔다. 측정·가이드만으로 기여를 대체하지 않는다 |
