# 07. 제품 명세 — 초안

> 최종 발표에는 작동하는 제품이 필요하다. 벤치마크나 프롬프트 가이드만으로는 부족하다.

## 한 줄

알레르기를 선택하고 한국 식품 라벨을 찍으면, 선택한 항목에 대한 영어 경고가 근거와 함께 나오는 웹앱.

## 사용 흐름

1. 프로필: 미국 의무 표시 9개(Milk, Egg, Fish, Crustacean shellfish, Tree nuts, Peanuts, Wheat, Soy, Sesame) 중 본인의 알레르기를 선택한다.
2. 촬영: 원재료명이 보이게 라벨을 찍거나 사진을 올린다.
3. 결과: 선택한 항목마다 아래 3단계 중 하나와 근거 원재료를 보여준다.

| 판정 | 뜻 |
|---|---|
| 확인됨 (Confirmed) | 원재료에서 해당 알레르겐이 분명히 확인됨 |
| 추정 (Likely) | 유래·추출물·복합 원재료 등 근거는 있으나 확정 못 함 |
| 판정 불가 (Cannot determine) | 읽지 못했거나 구성이 불명확해 판단 불가 |

## 반드시 지킬 표시

- "검출되지 않음"이 "안전함"이 아님을 화면에 적는다.
- "미국 9개 항목 밖의 알레르기는 확인하지 않음"을 적는다.
- 사진이 흐리거나 읽지 못한 부분이 있으면 판정 불가로 넘긴다.

## 개인정보

- 알레르기는 건강 정보다 (개인정보 보호법상 민감정보 해당 가능). [검증 필요: 법률 검토]
- 서버에 저장하지 않는다. 브라우저 세션에서만 유지한다.
- 로그에 프로필을 남기지 않는다. 코드에서 실제로 지켜지는지 확인한 뒤에 발표에서 말한다.
- 개발·평가에는 가상 프로필만 쓴다. 실제 사람의 알레르기 정보를 모으지 않는다.
- 실제 서비스로 확장하려면 동의 절차와 법적 검토가 따로 필요하다.

## 범위 밖

- 9개 밖의 알레르기, 다른 나라 기준, 다국어 UI
- 로그인, 이력 저장, 푸시 알림
